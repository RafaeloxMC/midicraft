MIDIcraft is a Minecraft mod that lets you control the game with a MIDI controller! Yup, that's right — you can play the game with a (musical) keyboard!

## Features
- Control movement with a MIDI keyboard
- Bind any keyboard key to an action (soon)

## How it works
MIDIcraft recognizes your connected MIDI devices and reads their input! The input is then converted into Minecraft actions, which will then be executed.
